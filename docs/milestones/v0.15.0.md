# v0.15.0 — ReplaySSM 与默认 MTP3

发布日期：2026-09-15。上一版：[v0.14.0](v0.14.0.md)。

## 主要更新

- 新增 FP32 GDN ReplaySSM：MTP 验证时记录输入，仅将接受的前缀合入已提交的循环状态，减少多 token 草稿的状态保存开销；保留 snapshots 路径。
- IQ3/IQ4 启动脚本默认使用 `--spec-draft-n-max 3 --kvmem-mtp-state replay`。可通过 `SPEC_DRAFT_N_MAX` 和 `KVMEM_MTP_STATE` 覆盖；直接运行服务时，状态策略 `auto` 仍使用 snapshots。
- 图文基准支持 MTP 长度、预热和重复测量；更新 IQ3/IQ4 图文与 256K 工具任务结果及复测命令。
- 更新 llama.cpp 累计补丁及增量升级补丁，升级前检查完整性，冲突时保持原文件不变。子模块仍固定为 `b81c99b`。

ReplaySSM 当前支持已验证的单序列 CUDA Qwen 27B 路径，草稿长度 1–5；状态和记录保持 FP32。本版未包含 Q/mean-K GPU 聚合优化或生成预留 ring buffer。

## 验证与性能

CPU/CUDA GDN Record、CUDA Fold、各接受前缀及长序列测试通过；Q8/Q5 主 KV 下 MTP3/4/5 与 snapshots 的模型 logits 对照一致。启动器 13 项测试通过，补丁通过干净安装、旧版升级、重复执行及冲突保护检查。

RTX 5060 Ti 16 GiB 上，IQ3/IQ4 均完成图文任务和接近 256K 的多轮工具任务：

| 聚合 decode | IQ3 | IQ4 |
|---|---:|---:|
| 图文任务 | 38.55 token/s | 44.30 token/s |
| 256K 工具任务 | 31.74 token/s | 33.31 token/s |

测量条件、显存与 RAM 峰值、MTP 长度对比及复测命令见[推荐配置与性能](../recommended-config-performance.md)。IQ3 长程首次运行遇到 CUDA unknown error，同配置重试完整通过；该记录保留在性能文档中。

## 使用

```bash
git checkout v0.15.0
git submodule update --init
scripts/apply-patches.sh
scripts/build-cuda.sh
scripts/start-iq3.sh    # GPU Q8_0 视觉，主 KV Q8_0，36K / 16K
scripts/start-iq4.sh    # CPU BF16 视觉，主 KV Q5_0，32K / 12K
```

两个启动命令按需选用。主模型与视觉头文件需先按 [README](../../README.md) 准备，预算均按 1024 计算。回到快照状态路径可使用 `KVMEM_MTP_STATE=snapshots scripts/start-iq3.sh --restart`。
