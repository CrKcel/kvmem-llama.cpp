# v0.15.1 — host mean-K 单累加器

发布日期：2026-09-15。上一版：[v0.15.0](v0.15.0.md)。

## 主要更新

- host 侧 mean-K 不再为每块另存一份 mean 向量。只保留 token count 与 FP32 sum，读取时再做均值；tail checkpoint / rollback / 占用统计一并改掉。
- 行为与上一版缓存 mean 对齐（同一套 reciprocal）。覆盖块长 32/128、部分块、checkpoint 续写，以及统计与存储计数差异。
- 产品配方不变：仍是 ReplaySSM + 默认 MTP3。不含 Q/mean-K GPU 聚合，也不含生成预留 ring buffer。

## 验证

`raw_kv_store` 等 host 测试在该改动上通过；主干与 MTP adapter 语法检查通过。

## 使用

```bash
git checkout v0.15.1
git submodule update --init
scripts/apply-patches.sh
scripts/build-cuda.sh
scripts/start-iq3.sh
scripts/start-iq4.sh
```

相对 `v0.15.0` 无需改启动参数。
