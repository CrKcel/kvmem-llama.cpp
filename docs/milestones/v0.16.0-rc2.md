# v0.16.0-rc2 — Native Windows preview

- Native Windows/MSVC support, portable timing and bundled Web UI lookup.
- Explicit memory-only configuration on Windows; reject NVMe options instead of silently ignoring them.
- Preserve llama.cpp-style `-ctk/-ctv` and `--cache-type-k/--cache-type-v`; reject mismatched quantized K/V before model loading with actionable diagnostics.
- CUDA compiler baseline 13.2.86; runtime and optional quantizer packages are separate.
- Build/package scripts, matching patched source snapshot, checksums and explicit validation scope.

The rc2 Windows binary passed eight model-free tests, 52 KV argument cases and
four IQ3 short-text checks. A preceding deployment completed a synthetic 256K
tool-result test; this is supplementary evidence, not rc2 binary certification.
Raw tool-call markup with `tool_choice: none` remains a known behavior to
investigate. No fix is claimed. IQ4, vision and full rc2 256K are not validated.
See `scripts/windows/README.md` and the release validation report.

Linux users may keep the rc1 prebuilt package. This release does not replace it.
