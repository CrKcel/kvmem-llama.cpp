## 1. 这一版是什么

在 `v0.9.0` packed 路径上补齐进程内前缀和 chat 协议：

- **Decode mean-K（计划 B）：** retrieval pin 之后，接受的 token 在 GPU 上对 pre-RoPE K 做 running sum；块写满或本轮结束 D2H 一份 mean。MTP 草稿不算（verify stash → accept 后 `commit`）。
- **Prefix reuse（计划 C）：** `llama-kvmem-server` 不再每请求 `memory_clear`。完整 messages 重新 tokenize，LCP 对齐则 `seq_rm(n_past,-1)` + GDN catch-up，只 prefill 后缀。
- **Chat tools T1–T5：** `/v1/chat/completions` 走 `common/chat` + `common_sampler`。服务端不执行工具。query span = 最后一条 **user**（不是 `role=tool`）。tool 第二轮允许 LCP < cached（GDN catch-up）。
- **MTP + 中间 query：** GDN catch-up / query replay 只走 trunk；draft 在 query `seq_rm` 后按序补齐（M-RoPE 不能在 `X >= Y` 时填洞）。

未进此 tag：阶段 D `state_write` 落盘；T6 `response_format` / `json_schema`；MTP 产品默认仍 **none**。
