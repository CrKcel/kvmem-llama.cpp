## 1. 这一版是什么

在 `v0.7.0` GPU stage-in 上把 128k retrieval 里剩下的几次大拷贝收成 **一块 32 MiB packed slab + GPU gather/scatter**：

- **stage-in**：packed q8 按 32 MiB 入 GPU slab，再 dequant / orig-pos RoPE / FWHT / quant（K）或 D2D（packed V）
- **stage-out**：gather kernel 把散落的 packed V 打进同一块 GPU slab，一次 D2H；双 host pin，host 写 slab N 和 GPU 做 N+1 重叠
- **layout**：resident K+V 用 gather/scatter kernel，不再逐块 D2D（`layout_*` 231 ms → ~8 ms）
- **跳过无用 GPU-format spill**：`--kvmem-cpu-gb` / `--kvmem-nvme-gb` 都关时不分配 `scratch_`、不做 `copy_block_to_host`（packed V 已在 RawKvStore）
- host packed-V 整块写入用 `vector.assign(src, src+need)`，不再先填零

额外持久显存：**32 MiB** GPU slab（+ 两块 32 MiB pinned host，不算 VRAM）。`KVMEM_RETR_SUM` 增加 `stage_out_gpu_ms` / `stage_out_host_ms`。

明确还没做 / 试过撤掉：

- host bump arena、prefault、`write_v_gpu_slab`（128k `stage_out` host 仍 ~400 ms，无墙钟收益，不进此 tag）
- `--kvmem-harvest-v` 默认仍 **off**
- GPU `--kv-dtype fp8` / 改 FA / compact-window RoPE
- P6 Metal / Vulkan；IQ3_S MTP

## 4. 速度（只记录）

IQ3_S 128k / 60k active / q8 / 5090 / bt=128 / `-b 512` no-mtp：

| | prefill | retrieval_ms | decode | 显存峰值 |
|---|---:|---:|---:|---:|
| v0.6.0 host Hadamard | 780 | 44498 | 33.0 | 14896 |
| v0.7.0 GPU stage-in | 787 | 3392 | 34.2 | 14896 |
| **v0.8.0 slab + gather/scatter** | **825** | **1367** | **33.8** | **14928** |

`KVMEM_RETR_SUM` v0.8.0：`stage_out_ms=430`（`gpu=11` `host=418`）`layout_d2h+h2d≈8.5` `copy_ms=207` `set_ms=506` `n_raw=248`。相对 v0.7.0，retrieval 3.4 s → 1.4 s；峰值 +32 MiB 是 GPU slab。剩下三块：`set` ~507、`stage_out` host ~418、`copy` ~207。
