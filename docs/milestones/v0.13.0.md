## 1. 这一版加什么

### 1.1 Chat Completions 图片

`messages[].content[]` 支持 `text` 与 `image_url`（base64 data URI 或 HTTP(S)）。`--mmproj` 加载视觉 projector（默认 IQ3 脚本用 Unsloth `mmproj-Q8_0.gguf`）。`--mmproj-offload` / `--no-mmproj-offload` 把 encoder 放 GPU 或 CPU。`--image-max-tokens` 限制原生动态分辨率（默认 512）。未配 projector 时图片请求 HTTP 400。

复用 llama.cpp `mtmd` 与原生解码，没有自写 ViT/RoPE。

### 1.2 视觉 token 与 KVMem

逻辑 KV 行、原生 M-RoPE pos、GPU slot 分开。视觉段主 KV 与 MTP 草稿 KV 可换出/恢复。同一会话复用有效文本+图片前缀；图片后的文本仍可用 MTP。找不到可恢复 recurrent 检查点时自动按 cache miss 重填，不必客户端 `cache_reset`。

host `RawKvStore` / `kvmem_store` 增加按行映射，配合视觉变长段。

### 1.3 Patch 回放

`scripts/apply-patches.sh` 改为对累计 `llama-kvmem-current.patch` 做 `git apply`（已应用则跳过；旧 KVMem 树可走 `multimodal-upgrade.patch`）。不再 `git am` 编号系列。

## 2. 怎么复现

```bash
git checkout v0.13.0
git submodule update --init
source scripts/gpu.sh small
scripts/apply-patches.sh
scripts/build-cuda.sh
.venv/bin/ctest --test-dir build --output-on-failure -R kvmem
```

IQ3 + 视觉（5060 Ti / 5090）：

```bash
scripts/start-iq3.sh
# MMPROJ_DEVICE=cpu scripts/start-iq3.sh --restart
```

图片请求示例见实现报告。`python3 scripts/multimodal_canary.py` 做小模型/隔离探测（不杀 18200）。
